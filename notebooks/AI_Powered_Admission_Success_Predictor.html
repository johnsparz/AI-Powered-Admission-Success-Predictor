Phase 3 – Feature Engineering¶

Step 3.1 – Create the Program Feature

def assign_program(row):
    if row["gre_score"] >= 330 and row["cgpa"] >= 9.2:
        return "Computer Science"
    elif row["gre_score"] >= 325 and row["cgpa"] >= 9.0:
        return "Data Science"
    elif row["gre_score"] >= 320 and row["cgpa"] >= 8.8:
        return "Artificial Intelligence"
    elif row["gre_score"] >= 315 and row["cgpa"] >= 8.5:
        return "Software Engineering"
    elif row["gre_score"] >= 310 and row["cgpa"] >= 8.2:
        return "Information Technology"
    else:
        return "Computer Engineering"

df_clean["program"] = df_clean.apply(assign_program, axis=1)

Step 3.2 – Create the Application Completion Feature

df_clean["application_completion"] = np.where(
    (df_clean["research"] == 1) &
    (df_clean["sop"] >= 3.5) &
    (df_clean["lor"] >= 3.5),
    "Complete",
    "Incomplete"
)

Exploratory Data Analysis (EDA) Summary¶

Overview¶

The Exploratory Data Analysis (EDA) phase was conducted to understand the structure of the dataset, identify patterns among the variables, and discover relationships that may influence graduate admission decisions. Several univariate and bivariate visualizations were created to examine the distribution of academic features and their relationship with the admission outcome.

Key Findings¶

1. Balanced Admission Classes¶

The admission distribution shows that the dataset is well balanced, with approximately equal numbers of admitted and non-admitted applicants.

  • Admitted: 204 applicants
  • Not Admitted: 196 applicants

A balanced target variable is beneficial because it reduces the likelihood of model bias toward one class and provides a suitable foundation for supervised classification.

2. GRE Scores¶

The GRE score distribution approximates a bell-shaped curve with most applicants scoring between 310 and 325.

This indicates that applicants generally possess competitive GRE scores, while extremely low or exceptionally high scores are relatively uncommon.

3. TOEFL Scores¶

Most TOEFL scores fall between 100 and 112.

The distribution suggests that applicants generally demonstrate strong English language proficiency, which is expected for graduate school applications.

4. CGPA Distribution¶

Applicant CGPAs are concentrated between 8.0 and 9.3 on a 10-point grading scale.

The distribution indicates that most candidates have strong academic performance, with relatively few applicants having low CGPAs.

5. University Rating¶

Applicants originate primarily from universities with ratings between 2 and 4.

University rating 3 appears most frequently, suggesting that applicants from mid-ranked institutions make up the largest proportion of the dataset.

6. Statement of Purpose (SOP)¶

Most SOP ratings lie between 3 and 4.

This indicates that the majority of applicants submitted reasonably strong statements of purpose rather than exceptionally weak or outstanding ones.

7. Letter of Recommendation (LOR)¶

The LOR ratings follow a distribution similar to the SOP ratings.

Most applicants received recommendation scores between 3 and 4.5, indicating generally positive academic recommendations.

8. Research Experience¶

Applicants with research experience exhibit substantially higher admission rates than applicants without research experience.

This suggests that research experience is an important characteristic associated with successful graduate school applications.

9. Program Distribution¶

Admission rates differ across the engineered program categories.

This pattern is expected because the program feature was created using rule-based thresholds based on applicants' GRE scores and CGPA. Therefore, programs associated with stronger academic profiles naturally display higher admission rates.

These results should not be interpreted as actual university admission statistics but rather as outcomes of the feature engineering process.

10. Gender Distribution¶

The admission rate is nearly identical for both male and female applicants.

This observation is expected because the gender feature was synthetically generated for demonstration purposes and does not represent actual applicant demographics.

Consequently, no real-world conclusions regarding gender and admission decisions should be drawn from this feature.

11. Correlation Analysis¶

The correlation heatmap indicates that several academic variables are positively associated with admission probability.

Among the strongest predictors are:

  • CGPA
  • GRE Score
  • TOEFL Score
  • Research Experience

These variables appear to contribute most strongly to admission outcomes and are expected to play significant roles during model training.

No severe multicollinearity is observed that would prevent the use of standard machine learning algorithms.

Overall Conclusion¶

The exploratory analysis demonstrates that the dataset is clean, well balanced, and suitable for machine learning.

Academic performance indicators—including GRE score, TOEFL score, CGPA, and research experience—show the strongest relationships with admission outcomes.

The engineered features successfully satisfy the project requirements while maintaining logical consistency within the dataset.

The dataset is now fully prepared for the machine learning phase, where multiple classification algorithms will be trained, evaluated, and compared to identify the best-performing admission prediction model.

numeric_transformer = Pipeline(
    steps=[

categorical_transformer = Pipeline(

        ("encoder", OneHotEncoder(handle_unknown="ignore"))
    ]
)

)

Step 8.6 – Create a Simple Rule-Based Explanation Function

def generate_explanation(applicant):
    """
    Generate a simple explanation for an applicant profile.
    """

    reasons = []

    if applicant["cgpa"] >= 9:
        reasons.append(
            "Excellent CGPA increased admission likelihood."
        )

    if applicant["gre_score"] >= 325:
        reasons.append(
            "High GRE score strengthened the prediction."
        )

    if applicant["toefl_score"] >= 110:
        reasons.append(
            "Strong TOEFL score improved the application."
        )

    if applicant["research"] == 1:
        reasons.append(
            "Research experience positively influenced the model."
        )

    if applicant["application_completion"] == "Complete":
        reasons.append(
            "A complete application strengthened the prediction."
        )

    if len(reasons) == 0:
        reasons.append(
            "No particularly strong positive indicators were detected."
        )

    return reasons
